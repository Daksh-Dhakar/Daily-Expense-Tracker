# Daily Expense Tracker

## Project Overview

Daily Expense Tracker is a simple Python project used to record and manage daily expenses.

The user can add expenses, view all expenses, calculate the total and average expense, clear all expenses, and exit the program.

## Features

- Add a new expense
- View all expenses
- Calculate total expense
- Calculate average expense
- Clear all expenses
- Simple menu-based program

## Technologies/Tools Used

- Python
- VS Code / IDLE
- GitHub

## How to Run the Project

1. Install Python on your computer.
2. Download or clone the project from GitHub.
3. Open the project in VS Code or Python IDLE.
4. Run the Python file.
5. Select an option from the menu.

## How to Test the Project

1. Choose option 1 to add an expense.
2. Enter the expense amount.
3. Choose option 2 to view all expenses.
4. Choose option 3 to calculate the total and average.
5. Choose option 4 to clear all expenses.
6. Choose option 5 to exit the program.
