## Problem Statement

Managing daily expenses manually can be difficult and time-consuming. People may forget how much they spend during the day. This project provides a simple Python program to record expenses and calculate the total and average spending.

## Scope of the Project

The project focuses on basic daily expense management. Users can add expenses, view recorded expenses, calculate total and average expenses, and clear all stored expenses. It is a simple console-based application and does not use a database.

## Target Users
Students
Beginners learning Python
People who want to keep track of simple daily expenses


## High-Level Features
Add Expense: Allows users to enter and save a new expense.
View Expenses: Displays all recorded expenses with numbers.
Calculate Total and Average: Calculates the total and average of recorded expenses.
Clear Expenses: Removes all recorded expenses.
Exit: Closes the program safely.
Input Validation: Handles invalid menu choices by displaying an error message.
